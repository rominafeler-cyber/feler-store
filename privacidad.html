Política de privacidad

Última actualización: octubre de 2026.

Feler es un sitio de orientación y comparación de productos que utiliza enlaces de afiliado de Amazon.ca.

Registro y cuentas

Actualmente no ofrecemos cuentas de usuario. El formulario de registro es una demostración, está deshabilitado y no envía información a un servidor de Feler.

Favoritos en este navegador

Al marcar productos favoritos, Feler utiliza el almacenamiento local del navegador (localStorage, clave «feler-favoritos-v1») para conservar la selección. No se sincroniza entre dispositivos ni se envía a una cuenta de Feler. Puedes borrar los favoritos mediante los controles de tu navegador para eliminar los datos del sitio.

Enlaces externos y servicios de terceros

Cuando haces clic en un enlace de Amazon.ca, sales de Feler y se aplican las prácticas de privacidad de Amazon. El sitio utiliza GitHub Pages para su publicación y Google Fonts para determinadas tipografías. Estos proveedores pueden procesar datos técnicos necesarios para prestar sus servicios, de acuerdo con sus propias políticas.

Datos técnicos

Feler no dispone actualmente de un sistema propio de registro de cuentas ni de analítica configurada por esta versión del sitio. El proveedor de alojamiento puede procesar datos técnicos de conexión, como la dirección IP, para servir la página y garantizar su seguridad.

Actualizaciones

Esta política se revisará si incorporamos registro real, estadísticas de visitantes, boletines, formularios de contacto u otras funciones que recopilen información personal.

Algunos enlaces son de afiliado. Feler puede recibir una comisión por compras que cumplan los requisitos, sin costo adicional por utilizar el enlace.

As an Amazon Associate I earn from qualifying purchases.
